# Git 文件与本地数据

提交功能源码、测试代码、公开且去除账户信息的测试样本、依赖锁文件、版本与构建配置、通用功能文档。`testdata/` 中用于回归的固定目录和接口样本属于测试输入，不是可随意清理的缓存。

不提交以下本地文件：

- `artifacts/`、`dist/`、发布压缩包、编译二进制和重复的发布源码副本。
- `node_modules/`、Python 缓存、TypeScript 增量编译文件、测试输出与日志。
- `scratch/` 内新建的临时运维脚本、采集快照和部署工作文件。历史已跟踪的通用脚本保持原样；忽略规则不会自动取消已有跟踪。
- 真实账户环境配置、数据库、SQLite 辅助文件、真实订单实战报告及账户专用实战测试程序。

数据库中的账户、订单、目录检测基线、任务状态和防重复记录是持久化业务数据。它们不进 Git，但必须保留并单独备份；不能作为缓存清除，也不能为了重置页面计数删除。数据库迁移代码和 `schema.sql` 则必须提交。

本次仓库整理仅将已跟踪的发布包、Linux 二进制、`scratch/deploy-payload/` 发布副本和采集 JSON 移出 Git 索引，本地文件继续保留。旧提交中的文件不会因此消失；未重写 Git 历史。

`docs/audit-2026-11-06/` 中的文件索引是当时的历史审计快照，其中列出的本地产物可能已不再随仓库分发，不代表当前应当提交这些文件。

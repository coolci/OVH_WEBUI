# 抢购历史排序

抢购历史新增排序选择，桌面表格和手机卡片使用相同顺序。

- 默认“已付款优先”：下单成功且 OVH 状态为 `delivering`（已付款·交付中）或 `delivered`（已付款·已交付）的记录置顶。两类作为同一组，按下单时间从新到旧排列；其余记录同样按下单时间倒序排列。
- 已提交或结果待核对的撤单记录不置顶，避免把“撤单已申请”等状态混入已付款交付组。
- 可改选“下单时间：最新在前”或“下单时间：最早在前”，按时间统一排序。
- 排序选择保存在当前浏览器，刷新和重新进入页面后保留；不能使用浏览器存储时仍可在当前页面切换。
- 排序与搜索、状态筛选和批量选择共同工作，只改变排列顺序，不更改记录和勾选身份。后台状态刷新后自动按当前排序重新排列。

验证：生产构建、修改文件 ESLint 与 103 项前端测试通过。新增覆盖两种已付款状态的置顶、撤单及失败记录排除、组内时间顺序、时区比较、正反时间排序、无效时间置后及查询缓存不被修改。

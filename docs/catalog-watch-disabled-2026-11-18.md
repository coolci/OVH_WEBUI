# 新增机型 / 配置自动下单停用

按用户要求停用服务器列表中的“新增机型 / 配置自动下单”，源代码保留。

- `ServersPage.tsx` 中的组件导入及挂载入口已注释；原组件、查询 hooks 和类型文件保留。
- `catalogwatch/watcher.go` 保留原默认开启初始化的注释，新实例默认关闭。生产工厂 `For` 在加载旧状态后强制持久化关闭，取消未提交的 pending 任务，保留历史、基线、成功及未决订单证据。
- `Run` 中的目录轮询、自动任务发现和下单调度两个循环整段注释，不再访问销售目录或提交新订单。
- GET `/api/catalog-watch` 保留供兼容查询，返回关闭状态；PUT 仍接受 `enabled=false`，`enabled=true` 返回 409，旧客户端不能恢复此功能。
- 已提交但结果未知的订单仍只读核对，确认未提交时终止；已成功订单继续进入原历史记录流程。不会为旧任务创建新订单。

普通抢购队列、针对指定机型的补货监控及其配置不属于本次停用范围。自动付款仍保持停用，订单历史页的手动支付和取消功能继续保留。

离线回归覆盖新安装默认关闭、旧库开启状态关闭并持久化、待处理任务停用而未决证据保留、后台只读核对、接口拒绝重新开启，以及编译后的正式服务器页无此入口。旧算法测试保留，用于验证保留代码和历史核对逻辑；均不调用真实 OVH 下单。

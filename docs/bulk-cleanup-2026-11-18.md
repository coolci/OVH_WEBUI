# 服务器监控、抢购历史与抢购队列批量清理

三个正式页面均新增逐条勾选、全选当前列表、已选数量、取消选择和清理选中按钮。历史页的桌面表格与手机卡片共享选择状态。

支持鼠标左键拖动框选多条记录；普通框选替换当前选择，Ctrl / Shift 框选追加选择。拖动接近列表滚动区域上下边缘会自动滚动；Esc 可取消正在进行的框选并恢复原选择。按钮、输入框、链接、复选框保持原交互，触屏保持勾选方式。选好后可按 Delete 或点击“清理选中”进入确认，不会在松开鼠标时直接删除。

## 选择范围

- 可以只选一项，也可选择多项。
- 历史页和队列页的全选仅作用于当前搜索及状态筛选结果。筛选后隐藏的项目取消选择，避免误清理。
- 轮询新增的项目不会自动被勾选。
- 确认框展示本次项目清单，并固定记录 ID / 订阅配置键；轮询或其他页面的变化不会扩大本次删除范围。
- 监控订阅按型号和配置键定位，空配置键显式发送，区分“全部配置”和同型号其他硬件配置。

## 清理语义

| 页面 | 清理结果 |
| --- | --- |
| 服务器监控 | 移除选中订阅及其监控变化历史，停止这些订阅后续通知和自动入队；已有队列任务需要在队列页处理 |
| 抢购历史 | 仅删除选中的本地历史记录，不取消 OVH 订单，不退款；付款和撤单防重复记录保留 |
| 抢购队列 | 通过原单任务删除链路停止选中的任务，保留自动建单停止保护；已发出的结账可能完成，不会取消已创建的 OVH 订单 |

批量操作最多同时发送 4 个删除请求，不调用清空全部接口。无自动重试。成功和失败分别统计，失败项在确认框内保留，可单独重试；已不存在的记录视为目标状态已达成。

新增鉴权接口 `DELETE /api/purchase-history/:id` 精确删除本地记录，重复删除幂等。历史删除与全表保存共享串行锁，数据库失败时内存不变，防止旧快照将已删记录写回。

监控删除复用现有精确配置身份，改为在持久化成功后移除运行时订阅，与订阅保存共用串行锁；失败时返回错误，原订阅保留。

- 前端生产构建、类型检查、修改文件 ESLint 和 101 项前端测试通过。
- `app`、`handlers`、`monitor`、`router` 后端测试通过。
- 新回归覆盖筛选选择、后台新增、确认快照、并发上限、部分失败、只重试失败项、精确历史 ID、历史与新订单并发保存、财务防重复记录保留、同型号多配置并发删除及数据库失败。
- 用正式页面组件和独立内存 API 模拟数据完成离线点击：历史多选、队列筛选全选和取消确认、监控两套配置清理并保留未选配置。没有删除实际用户记录，也没有提交 OVH 付款或撤单。
- OpenAPI 与后端均为 267 个路由，无两者之间的缺失项。
